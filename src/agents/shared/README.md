# Shared

Esta carpeta contiene configuración compartida y reusable entre herramientas de IA.

Reglas:

- Mantener contenido global y neutral, no acoplado a un proyecto concreto.
- Priorizar español para instrucciones y documentación.
- Evitar duplicación: lo común va en `shared`, lo específico en cada herramienta.

Estructura:

- `agent-guidelines.md`: guía personal global para cualquier herramienta.
- `skills/`: skills compartidas en formato estándar.
- `agents/`: definiciones de subagentes compartidos.
- `rules/`: reglas reutilizables.
- `prompts/`: prompts reutilizables.
- `mcp/`: configuración y notas de MCP compartidas.
- `hooks/`: hooks compartidos.
